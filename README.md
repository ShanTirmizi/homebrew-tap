# ShanTirmizi's Homebrew tap

```sh
brew install --cask shantirmizi/tap/utter
```

| Cask | What it is |
| --- | --- |
| [utter](https://github.com/ShanTirmizi/utter) | Free, private voice dictation for macOS |

Update with `brew upgrade --cask utter`. Remove with `brew uninstall --cask utter`,
or `brew uninstall --zap --cask utter` to also delete its settings, history and
downloaded speech models. Your API keys stay in the macOS Keychain until you
remove them there.
